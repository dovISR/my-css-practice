# Visual CSS Challenges

Part of [Practices](../README.md). Five website pages for after [01 — CSS fundamentals](../lesson-01/README.md). You still edit `style.css`. The HTML is already written. These pages are not graded by `npm test`.

Each one is a small site: travel, a film shelf, a profile, a restaurant, and a shop. The layout work is flexbox, the box model, type, color, and photographs. There is no JavaScript, React, Tailwind, or Bootstrap.

Open an exercise `index.html` with Live Server, then save `style.css` to reload the browser. Install steps are in [extensions/README.md](../../extensions/README.md). The finished page in each exercise is `solution/index.html`. A `preview.png` next to the brief shows that same page.

Do them in order. 06 is one row of cards. 07 lets that row wrap and adds hover. 08 nests a column inside a centered page. 09 combines a navigation row, a split hero, and a menu. 10 is a full product gallery.

Lesson 01 stays the graded path: color, border, display, float, then flex. Finish [Card Row](../lesson-01/05-flex/01-card-row/README.md) before these pages if flex is new.

Photographs are stored in each exercise under `assets/images/`. Credits and licenses are in the `credits.md` file beside them. The pages use original names: Atlas, CineVerse, Alex Morgan, Taste & Table, and UrbanGear.
