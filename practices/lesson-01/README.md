# 01 — CSS fundamentals

Part of [Practices](../README.md). Fifteen chapters, in three levels. Each level uses the ideas from the level before it.

Finish a chapter before the next one. Open the exercise `index.html` with Live Server. Install steps are in [extensions/README.md](../../extensions/README.md).

`npm test` grades chapters 01–05 only. Chapters 06–15 have no `test.js`. Check those by eye against the preview and the `solution/` folder.

## Level 1 — CSS fundamentals

Exercises 01–05. One property family at a time, on a small fixture. You edit `style.css`. The test reads the computed style.

| Chapter | Exercises | Objective |
| --- | --- | --- |
| [01 — Color](01-color/README.md) | Text Color | Set a text color the test can read |
| [02 — Border](02-border/README.md) | Solid Border | Draw a solid border on every side |
| [03 — Display](03-display/README.md) | Inline Block | Change inline boxes into inline-block boxes |
| [04 — Float](04-float/README.md) | Float Aside | Float an aside to the right |
| [05 — Flex](05-flex/README.md) | Card Row | Lay cards out in a row with a gap |
