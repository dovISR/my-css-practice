# Practices

Part of [CSS Practice](../README.md). Each lesson is one course presentation. Inside it, chapters and exercises keep their names.

You edit `style.css`. The HTML page stays as it is. After the test for an exercise passes, open its `index.html` with Live Server and review the page. Saving `style.css` reloads the browser. Install steps are in [extensions/README.md](../extensions/README.md).

| Lesson | README |
| --- | --- |
| [01 — CSS fundamentals](lesson-01/README.md) | `practices/lesson-01/README.md` |

Lesson 01 has fifteen chapters, in three levels. The map is [lesson-01/README.md](lesson-01/README.md).

Chapters 01–05 are graded with `npm test`. You edit `style.css`.

Chapters 06–10 are short visual pages: [Dog Gallery](lesson-01/06-dog-gallery/README.md), [Border Playground](lesson-01/07-border-playground/README.md), [Picture Frame Studio](lesson-01/08-picture-frames/README.md), [Animal Alignment](lesson-01/09-animal-alignment/README.md), and [Mini Profile Cards](lesson-01/10-profile-cards/README.md). You edit `css/practice.css` and leave `css/base.css` as it is.

Chapters 11–15 are website projects: [Travel](lesson-01/11-travel-explorer/README.md), [Cinema](lesson-01/12-movie-gallery/README.md), [Profile](lesson-01/13-profile-dashboard/README.md), [Restaurant](lesson-01/14-restaurant-landing/README.md), and [Store](lesson-01/15-urban-store/README.md). You edit `style.css`.

Chapters 06–15 are checked by eye against `preview.png` and the `solution/` folder.
