# Practices

Part of [CSS Practice](../README.md). Each lesson is one course presentation. Inside it, chapters and exercises keep their names.

You edit `style.css`. The HTML page stays as it is. After the test for an exercise passes, open its `index.html` with Live Server and review the page. Saving `style.css` reloads the browser. Install steps are in [extensions/README.md](../extensions/README.md).

## Visual CSS challenges

Five website pages for after lesson 01. Students practice flexbox, the box model, type, color, and photographs by building a travel page, a film shelf, a profile, a restaurant, and a shop. Each folder has the HTML, a starter `style.css` with TODO comments, a `preview.png`, and a finished page in `solution/`. They are not part of `npm test`. The briefs are in [visual-challenges/README.md](visual-challenges/README.md).
