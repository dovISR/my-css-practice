# Curriculum

Part of [CSS Practice](../README.md). This folder is the source of truth for what the course teaches. The graded pages stay in [practices/README.md](../practices/README.md).

Each module folder can be read on its own. A presentation tool or a notebook source needs that folder, not the test runner and not the answer branch.

## Files in a module

| File | What it is for |
| --- | --- |
| [specification.md](modules/css.color/specification.md) | Objectives, prerequisites, and the exercises that belong to the module |
| [study-guide.md](modules/css.color/study-guide.md) | The explanation a student or a teacher reads before the exercise |
| [presentation-outline.md](modules/css.color/presentation-outline.md) | Slide-by-slide classroom outline |
| [podcast-brief.md](modules/css.color/podcast-brief.md) | Discussion brief for an audio lesson |
| [assessment.md](modules/css.color/assessment.md) | How understanding is checked, and which objective each check belongs to |

The color links above are the pattern. Every existing module in this repo uses the same five files.
